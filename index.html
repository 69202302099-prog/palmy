ขั้นตอนเผยแพร่ขึ้น GitHub Pages

  1. สร้าง Repository ใหม่: ไปที่ GitHub.com แล้วสร้าง Repository เช่น my-portfolio
  2. บันทึกไฟล์เป็น index.html: คัดลอกโค้ดทั้งหมดนี้ บันทึกลงในไฟล์ชื่อ index.html
  3. อัปโหลดไฟล์: กดปุ่ม Add file > Upload files นำไฟล์ index.html ขึ้นสู่ GitHub
  4. เปิดใช้งาน Pages: ไปที่ Settings > Pages ในช่อง Source เลือก main หรือ master แล้วกด Save
  5. เข้าชมเว็บไซต์: เว็บไซต์จะพร้อมใช้งานในไม่กี่นาทีที่ URL: https://[your-username].github.io/[repo-name]/
